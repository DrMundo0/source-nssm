# TASK：NSSM 开发任务拆解

## 1. 任务目标

本文档将 NSSM 项目的工作拆分为清晰的开发任务，用于协作实施、进度管理、验收评审和后续迭代规划。

## 2. 任务分层

### 2.1 基线与架构任务
- 任务 1：确认支持目标
  - 目标：明确 Windows 7+、32/64 位构建要求
  - 产出：项目兼容性基线说明

- 任务 2：梳理原作与当前 fork 差异
  - 目标：识别原始 NSSM 与当前维护版本的功能、兼容性和稳定性差异
  - 产出：差异清单和修复优先级

- 任务 3：整理模块边界
  - 目标：确立入口、服务、注册表、进程、IO、GUI、事件、钩子等职责
  - 产出：模块关系图与代码接口文档

- 任务 4：完善命令行入口设计
  - 目标：统一 start/stop/restart/install/edit/get/set/reset/unset/remove/list/processes/version 等命令
  - 产出：命令映射说明

### 2.2 核心功能任务
- 任务 5：实现服务安装与删除流程
  - 目标：支持 install/remove 能力
  - 验收：成功注册并删除服务

- 任务 6：实现服务生命周期控制
  - 目标：支持 start/stop/restart/pause/continue/status
  - 验收：服务状态变更符合预期

- 任务 7：实现基础配置项管理
  - 目标：支持应用路径、参数、工作目录、显示名称、描述等
  - 验收：配置项写入和读取正确

- 任务 8：实现账户和依赖管理
  - 目标：支持 ObjectName、DependOnService、DependOnGroup
  - 验收：依赖先后顺序与账号生效

### 2.3 进程与停止策略任务
- 任务 9：实现优雅停止策略
  - 目标：支持 Console/Window/Thread 级停止方法
  - 验收：关闭信号逐步执行，不出现直接强杀异常

- 任务 10：实现进程树终止
  - 目标：遍历并终止子进程
  - 验收：进程树清理完整

- 任务 11：实现优先级与亲和性配置
  - 目标：AppPriority、AppAffinity、AppNoConsole
  - 验收：设置值与行为一致

### 2.4 日志与环境任务
- 任务 12：实现 stdout/stderr 重定向
  - 目标：将程序输出写入日志文件
  - 验收：日志内容可观察

- 任务 13：实现日志轮转
  - 目标：支持按时间和大小轮转
  - 验收：日志会按策略切分并保留文件

- 任务 14：实现环境变量配置
  - 目标：支持 AppEnvironment 和 AppEnvironmentExtra
  - 验收：变量注入和替换行为正确

### 2.5 退出动作与恢复任务
- 任务 15：实现退出动作控制
  - 目标：支持 Default/Ignore/Exit 等策略
  - 验收：服务按配置退出

- 任务 16：实现重启延迟与节流
  - 目标：控制 AppRestartDelay、AppThrottle
  - 验收：恢复策略符合配置

- 任务 17：实现事件钩子框架
  - 目标：支持 pre/post/change/resume 等事件
  - 验收：脚本/程序可按阶段执行

### 2.6 GUI 与体验任务
- 任务 18：完善 GUI 配置页
  - 目标：覆盖应用、详情、登录、依赖、进程、关闭、退出、I/O、轮转、环境、钩子等
  - 验收：界面参数与命令行保持一致

- 任务 19：移除无效功能项
  - 目标：删除 Win7+ 已失效的交互式服务配置
  - 验收：GUI 不含误导性选项

- 任务 20：统一中文文案
  - 目标：标准化 GUI 与消息资源的中文表述
  - 验收：术语统一、界面无中英混杂

### 2.7 构建与工程任务
- 任务 21：补充 GitHub Actions 构建流程
  - 目标：自动构建 32/64 位 Release
  - 验收：产物正确上传到 Artifacts

- 任务 22：验证 VS 工程升级与构建稳定性
  - 目标：兼容 VS 2019/2022
  - 验收：nssm.sln 可成功生成 Release 包

- 任务 23：整理输出物与发布说明
  - 目标：定义 exe/dll/artifact 产物目录
  - 验收：构建文档与发布说明一致

### 2.8 测试与回归任务
- 任务 24：进行功能回归测试
  - 目标：覆盖基础安装、启动、编辑、停止、删除
  - 验收：无明显回归

- 任务 25：进行稳定性测试
  - 目标：长时间运行和重启压力验证
  - 验收：无句柄泄漏、无异常退出

- 任务 26：完善测试文档
  - 目标：编写手工测试清单
  - 产出：测试步骤、风险、判定标准

## 3. 从任务到版本的推进方式

### 版本 3.0.0 目标
- 兼容 Windows 7+
- 移除交互式服务不再有效选项
- 提升稳定性和中文用户体验
- 完成自动构建和英文/中文消息统一

### 后续版本优先级
- 1）持续稳定性修复
- 2）日志轮转和事件钩子增强
- 3）测试框架补齐
- 4）文档与工程化标准化

## 4. 任务验收标准

### 功能验收
- 服务可以按预期安装、启动、停止、删除
- 参数配置有效且可恢复
- 轮转与日志行为满足需求
- 退出动作和重启策略按配置执行

### 质量验收
- 无明显构建失败
- 无明显稳定性缺陷
- 界面文案符合中文规范
- 事件日志与错误提示可辅助问题定位

## 5. 总结

任务拆解的核心思想是：先确保服务管理的“成立条件”与“稳定性”，再实现日志、环境、退出策略和钩子等扩展能力，最后完成 GUI 和工程化交付。这个路线兼顾了项目的原始价值和后续维护性，适合在 Windows 服务管理场景中长期演进。
