## 说明

该仓库是一个基于 NSSM 原作进行维护增强的 Windows 服务管理工具，核心目的是让任意可执行程序以 Windows 服务方式长期稳定运行，并提供安装、编辑、移除、启动、停止、重启、I/O 重定向、日志轮转、环境变量、依赖与退出动作等能力。

除上述新增文档外，README 中已保留项目的构建方式、兼容性说明与功能概览，便于用户快速上手和理解该工具的使用方式。
